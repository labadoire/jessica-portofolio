PROJECT 03 / DATA ENGINEERING

Distributed Data Warehouse Implementation

Designing and evaluating a distributed data warehouse using PostgreSQL and Docker to process sales data across multiple database nodes.

FIELD

Data Engineering · Data Warehousing

TOOLS

PostgreSQL · SQL · Docker

APPROACH

Horizontal Data Distribution

01 / OVERVIEW

Processing data across multiple database nodes.

This project explores the implementation of a distributed data warehouse using PostgreSQL and Docker. A dataset containing 100,000 sales records was distributed across three database nodes based on transaction year.

The objective was to demonstrate how distributed processing divides analytical workloads while maintaining consistency and accuracy in the final query results.

02 / SYSTEM ARCHITECTURE

One coordinator. Three distributed nodes.

The architecture consists of one central PostgreSQL coordinator and three distributed PostgreSQL database nodes, each responsible for storing sales data from a specific year.

03 / IMPLEMENTATION

From data distribution to global analysis.

Sales transactions were horizontally distributed across three PostgreSQL nodes according to their transaction year. Each node independently processed its assigned subset of the dataset.

  • Distributed 100,000 sales records across three PostgreSQL nodes.
  • Validated record counts and transaction date ranges for each node.
  • Executed SQL aggregation queries independently on each node.
  • Combined local product-level aggregates to calculate global sales totals.
  • Verified the global Top 10 products against single-node query results.

Combining local insights into global results.

06 / KEY FINDINGS

Scaling analytical workloads through distribution.

  • Successfully distributed 100,000 sales records across three PostgreSQL nodes.
  • Demonstrated independent local processing and product-level aggregation.
  • Reduced the records used in final aggregation from 100,000 raw sales rows to 3,000 summarized records.
  • Verified matching Top 10 product rankings between single-node and distributed results.

This project strengthened practical understanding of distributed data architecture, SQL query processing, workload distribution, and analytical result verification.
